EDUNUSA LMS — PROTOTYPE UI IMK
================================
Cara menjalankan:
1. Ekstrak semua isi ZIP ke satu folder.
2. Buka index.html di browser modern.
3. Jangan memisahkan style.css, script.js, logo-edunusa.png, tema.jpg, dan folder course-art.

Pembaruan desain:
- Banner sambutan lebar memakai tema.jpg.
- Ilustrasi latar belakang mata kuliah berupa SVG lokal di folder course-art.
- Tata letak, warna, bayangan, jarak, kartu, navigasi dan responsivitas diperbarui.
- Fitur lama dipertahankan: dashboard, mata kuliah, tugas, nilai simulasi, pengumuman, kalender, profil, pencarian, filter, tambah/edit/hapus data, ekspor CSV, toast, dan penyimpanan lokal browser.

Catatan: prototype front-end untuk tugas IMK; belum terhubung ke server/database kampus. Nilai dan data awal adalah data demo.
